## Template Usage

For appending to monthly archive file `.claude/process-summary/2026/{MM}.md`:

```markdown
## {Topic}
- [2026-MM-DD] {Change title}（详见 [07月详情](2026/07.md#{topic})）
```

For updating index.md "最近30天变更" section:

```markdown
### 2026-MM-DD
- **{topic}**: {Brief description}（详见 [07月详情](2026/07.md#{topic})）
```
