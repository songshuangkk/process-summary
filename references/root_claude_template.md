# Top-Level CLAUDE.md Process Summary

Top-level `CLAUDE.md` stores only root module navigation.

## Format

```markdown
### Process Summary

- `shengchuang-module-quality/CLAUDE.md`: 质检、来料检、自检、检验任务
- `shengchuang-module-biz/CLAUDE.md`: PDA 接口、业务编排、跨模块 AppService
```

## Rules

- Keep one line per root module directory.
- Keep each line under 100 Chinese characters or 160 ASCII characters.
- Link to module-level `CLAUDE.md`, not detailed summary files.
- Replace existing root module entries in place.
- Do not include Recent Changes, Watch Out, long decisions, or dates here.
